## 5. Etiquetas
Chats → etiquetas. Sirven para saber qué clientes vienen de la web (la métrica que importa).

| Etiqueta | Cuándo |
|---|---|
| 🟢 Página web | El mensaje empieza con `*Cotización desde la página web*` |
| 🔵 Cliente nuevo | Primera vez que escribe |
| 🟡 Cotización enviada | Ya se le pasó precio, falta respuesta |
| 🟠 Confirmado | Viaje acordado, con fecha |
| ✅ Pagado | Viaje hecho y cobrado |
| ⭐ Cliente frecuente | Planta, ferretería o finca que repite |

## 8. Hábitos que más ayudan
- Contestar rápido: WhatsApp muestra al cliente cuánto tarda en responder.
- Etiquetar **cada** chat que llega de la web para poder contarlos a fin de mes.
- Publicar 2–3 estados por semana: fotos de cargas reales (sin datos del cliente).
- Guardar el número de cada cliente con nombre y lugar ("Don Carlos – Piñera Pital").
